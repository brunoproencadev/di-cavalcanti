Uma atividade em memória da Semana da Arte moderna de 22, proposta pelo professor [Vedilson](https://www.linkedin.com/in/vedilson/) para a matéria de Linguagem de Marcação.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias puras do desenvolvimento web para garantir o máximo de performance e customização, sem dependência de frameworks pesados:

- **HTML5**: Estruturação semântica em formato de slides.
- **CSS3 (Vanilla)**:
  - Design Responsivo e Variáveis CSS (Design Tokens).

## 📂 Estrutura do Projeto

Para garantir manutenibilidade e escalabilidade, o código foi separado seguindo boas práticas de desenvolvimento: 

```text
📦 projeto-fashion
 ┣ 📂 assets             # Imagens utilizadas no projeto
 ┃ ┗ 📜 di-cavalcanti.jpg
 ┃ ┗ 📜 di-cavalcanti-mulheres-protesando.jpg
 ┃ ┗ 📜 di-cavalcanti-mocas-com-violoes.jpg
 ┃ ┗ 📜 di-cavalcanti-meninas-cariocas.jpg
 ┃ ┗ 📜 di-cavalcanti-pescadores.jpg
 ┣ 📂 css
 ┃ ┗ 📜 style.css        # Estilização global e variáveis CSS
 ┣ 📜 index.html         # Estrutura do projeto e marcação
 ┗ 📜 README.md          # Documentação do projeto
```
